# 🎮 数独 & 俄罗斯方块 & 贪吃蛇

三个经典小游戏的网页合集，纯前端单页应用，部署在 GitHub Pages。

## 游戏

| 游戏 | 地址 |
|------|------|
| 数独 | [index.html](https://charlseyuan.github.io/sudoku-game/) |
| 俄罗斯方块 | [tetris.html](https://charlseyuan.github.io/sudoku-game/tetris.html) |
| 贪吃蛇 | [snake.html](https://charlseyuan.github.io/sudoku-game/snake.html) |

### 数独

- 三种难度：简单 / 中等 / 困难
- 计时、错误计数、自动校验
- 手机端支持数字键盘输入

### 俄罗斯方块

- 标准 7 种方块（I/O/T/S/Z/J/L）
- 计分、等级加速、下一个预览
- 键盘 + 手机触屏双控制
- 深色主题

### 贪吃蛇

- 经典网格贪吃蛇玩法
- 计分 + 最高分记录（localStorage）
- 键盘方向键 + 手机触屏滑动 + 按钮控制
- 速度随分数递增

## 技术栈

纯 HTML + CSS + JavaScript，零依赖，单文件部署。
